# ⌨️ Hotkeys Reference — Горячие клавиши для TUI

## 📋 Overview

Список всех горячих клавиш для навигации и управления в TUI интерфейсе.

---

## 🔑 Hotkey Matrix

| Клавиша | Действие | Описание |
|---------|----------|----------|
| `q`     | quit     | **Выход** из приложения |
| `n`     | new_task | **Новая задача** — создать задачу со статусом pending |
| `c`     | chat     | **Чат** — отправить сообщение в чат (открывает ввод) |
| `t`     | toggle_tasks | **Задачи** — показать/скрыть панель задач |
| `f`     | toggle_files  | **Файлы** — показать/скрыть панель файлов |
| `u`     | update   | **Обновить статус** — добавить сообщение в status bar |
| `h`     | help     | **Помощь** — отобразить список горячих клавиш |

---

## 🎯 Quick Reference

### Выход из приложения

```bash
q  # Выйти из TUI
```

### Создание новой задачи

```bash
n  # Создать новую задачу (status: pending)
```

### Отправка сообщения в чат

```bash
c  # Открыть ввод сообщения
# Затем ввести текст и нажать Enter
```

### Переключение панелей

```bash
t  # Показать/скрыть задачи
f  # Показать/скрыть файлы
```

### Обновление статуса

```bash
u  # Добавить сообщение в status bar
```

### Помощь

```bash
h  # Отображить список горячих клавиш
```

## 📊 Status Icons Reference

### Задачи

| Статус | Иконка | Описание |
|--------|--------|----------|
| pending | `⏳` | Ожидание выполнения |
| running | `▶️` | Выполняется сейчас |
| completed | `✅` | Успешно завершено |
| failed | `❌` | Ошибка выполнения |
| retrying | `🔄` | Повторная попытка |

### Сообщения чата

| Роль | Префикс | Цвет |
|------|---------|------|
| user | `[green]>[/green]` | green |
| ai | `[red]<[/red]` | red |
| system | `[dim]` | gray |

## 🎮 Input Handling

### Чат (клавиши)

- `Enter` — отправить сообщение
- `Backspace` / `Delete` — удалить символ
- `ESC` — отмена ввода сообщения
- `1-9`, `A-Z` — ввод текста

### Навигация

- Все горячие клавиши работают в любом состоянии UI
- Панели автоматически скроллятся при прокрутке чата

## 📝 Examples

### Пример 1: Быстрый старт

```bash
# Запуск TUI
python modules/tui/demo.py --mode full

# Горячие клавиши доступны сразу после запуска
```

### Пример 2: Интерактивное использование

```bash
# В чате:
c  # Нажать для открытия ввода

Enter    # Отправить

# Переключение панелей:
t  # Показать задачи
f  # Показать файлы
t  # Скрыть задачи (если были видны)
```

### Пример 3: Мониторинг задач

```bash
# Запуск TUI с MigrationAgent
python modules/tui/examples_api.py --mode integration

u  # Обновить статус (полезно при параллельном выполнении)
h  # Показать помощь если забыли клавишу
```

## 🔧 Advanced Usage

### Переключение видимости панелей

```python
from modules.tui.app import TUIApp

app = TUIApp(width=120, height=30)

# Скрыть задачи и файлы для компактного вида
app.show_tasks = False
app.show_files = False

app.run()
```

### Кастомизация hotkeys (для разработчиков)

```python
from modules.tui.app import TUIApp

class CustomTUIApp(TUIApp):
    """Кастомный TUI с изменёнными hotkeys."""
    
    HOTKEYS = {
        "q": ("quit", "Выход"),
        "x": ("new_task", "Новая задача (X)"),  # Изменил n на x
        "m": ("chat", "Чат (M)"),               # Изменил c на m
    }

app = CustomTUIApp(width=120, height=30)
app.run()
```

# 🖥️ TUI (Text User Interface) для AI-Агента

Текстовый интерфейс по аналогии с популярными консольными клиентами:
- **Claude Code** — от Anthropic
- **OpenCode** — OpenAI  
- **J Code** — JetBrains
- **Continue.dev** — VS Code extension CLI

## 📦 Установка

```bash
pip install -e .
```

**Зависимости** объявлены в [`pyproject.toml`](pyproject.toml):
- `requests` — вызовы Ollama API
- `rich>=13.0.0` — TUI рендеринг
- `python-dotenv` — загрузка `.env`

## 🚀 Запуск

### Демо режим:
```bash
python -m modules.tui.example
```

### Полная версия (будущая):
```bash
python -m modules.tui.app
```

## ⌨️ Горячие клавиши

| Клавиша | Действие | Описание |
|---------|----------|----------|
| `q`     | Quit     | Выход из приложения |
| `n`     | New Task | Создать новую задачу миграции |
| `c`     | Chat     | Отправить сообщение в чат |
| `t`     | Tasks    | Показать/скрыть задачи |
| `f`     | Files    | Показать/скрыть файлы |
| `u`     | Update   | Обновить статус выполнения |
| `h`     | Help     | Отображение помощи |

## 🔧 Компоненты

### `TUIApp` — основной класс приложения
- Event loop с обработкой событий клавиатуры
- Управление состоянием (chat, tasks, files)
- Рендеринг layout'а через Rich

### `ChatPanel` — чат компонент
- История сообщений LLM диалогов
- Максимум 50 последних сообщений
- Разделение на user/AI сообщения

### `TaskList` — список задач
- Группировка по статусу (pending/running/completed/failed/retrying)
- Прогресс бары для выполняемых задач
- Отображение ошибок для failed задач

### `StatusBar` — статус бар
- Счётчики задач и сообщений
- Последние системные уведомления
- Время выполнения

### `FileExplorer` — файловый эксплорер
- Группировка по папкам
- Иконки по типу файла (.py/.json)
- Отображение до 10 файлов на папку

## 🎯 Интеграция с MigrationAgent

Данные передаются через `shared_context.json`:
- **SDD документ** → передается в TDD
- **Тесты** → передаются в Coding
- **Результаты выполнения** → обновляются в статусе задач

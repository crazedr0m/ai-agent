# [T11] Итерационный план

**Тип**: grilling  
**Статус**: resolved  
**Метка**: wayfinder:grilling  

## Question

Как разбить работу на итерации?

## Resolution

**Три итерации**:

| Итерация | Фокус |
|---|---|
| **v1** | Рефакторинг архитектуры (ядро + агенты), трейсинг, MCP-клиент, улучшение парсера, декораторная регистрация инструментов |
| **v2** | MCP-генератор (агент пишет свои MCP-серверы), ретроспективы (анализ трейсов), self-improvement промптов |
| **v3** | Self-extension (агент пишет новые модули), meta-cognition (анализ архитектуры), RAG по трейсам |

## Последствия

- v1 — полная перестройка архитектуры, тесты
- v2 — надстройка над v1, новые модули
- v3 — экспериментальные функции саморазвития

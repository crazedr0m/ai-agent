## Сводка оригинальной концепции

### SUBTRAT — это архитектурный паттерн

**SUBTRAT** (Substrate — подложка/субстрат) — это не библиотека и не framework, а **способ организации памяти ИИ-агента**, вдохновлённый:

1. **Логарифмической шкалой частот** аудиоэквалайзера (16 полос)
2. **Геометрической адресацией** — контент адресуется не по имени, а по {частота, структурный_гейт, хэш}
3. **Non-gradient retrieval** — поиск без эмбеддингов, через детерминированные гейты

### LOG16 — это 16-полосная логарифмическая память

**LOG16** (Logarithmic 16) — это именно **16 log-полос** (band), где:

- **Band 15 (Core)** — статические системные правила, всегда доступны
- **Bands 8–14** — структурные факты, операционные workflow, схемы
- **Bands 1–7** — ассоциативные факты, открываются через gate_trigger
- **Band 0 (Spike/HF)** — быстрое забывание, immediate context

Формула распределения по band:

```
band = floor(log16(age + 1) - log16(access_count + 1))
```

- Чем старше факт без доступа → band растёт → ближе к Core
- Чем чаще доступ → band падает → остаётся актуальным

### Компоненты (обязательные vs опциональные)

**Обязательные для v1:**
- MemoryNode с полями id, payload, gate_trigger, frequency_band, access_count, last_accessed
- write_to_substrate — запись нового факта
- query_substrate — gated retrieval
- equalize_memory — пересчёт band + garbage collection
- status resource — визуализация распределения

**Опциональные (v2+):**
- SubstrateCompressor (NumPy) — векторная компактификация HF-спайков
- FractalKAN — нейросетевое расширение для предсказания decay
- Embedding-based семантический поиск
- Персистентность (SQLite/Redis)
- Фоновое переодическое equalize

### LOG16 vs MCP

LOG16 **не часть MCP-спецификации**. Это авторская идея Техножнеца, которая:
1. Описывает **архитектуру памяти** агента
2. MCP — это **протокол** для инструментов и ресурсов
3. LOG16 как MCP-сервер — это **адаптация**: упаковка SUBTRAT-памяти в MCP-инструменты (`write_to_substrate`, `query_substrate`) и MCP-ресурсы (`substrate://status`)

### Ключевые термины

| Термин | Определение |
|--------|-------------|
| Substrate | Многочастотная ассоциативная память |
| LOG16 | 16-полосная логарифмическая шкала decay |
| Gate Trigger | Ключевые слова для структурного доступа к факту |
| Frequency Band | Номер полосы (0–15), где хранится факт |
| Spike | Высокочастотный всплеск (Band 0, быстрое забывание) |
| Resonance | Среднечастотный резонанс (Bands 1–14) |
| Core | Низкочастотное ядро (Band 15, всегда доступно) |
| Equalize | Пересчёт band всех узлов + сборка мусора |
| Non-gradient | Поиск без градиентного спуска/эмбеддингов |
